How it works

A workflow with deliberate stopping points

Simple requests stay simple. Work that needs a plan moves through four explicit stages and pauses when you need to decide.

STEP 01

Analyze

Clarify the outcome, evidence, and unresolved boundaries.

STEP 02

Design

Choose the smallest sufficient path and make decisions visible.

STEP 03

Develop

Implement the approved tasks and attach focused verification.

STEP 04

Finalize

Close the plan only when delivery evidence is ready.

Product form

The host executes. Sopify keeps the work resumable

Sopify is a set of rules and Skills that installs into the AI coding tool you already use. It preserves plans, decisions, and verification evidence as project files in .sopify/.

~go runs or resumes the current plan from those files; routine questions and small fixes are answered directly without resuming a plan. A local handoff pointer provides a same-workspace resume hint.

FAQ

The short version

How does Sopify work with existing AI coding tools?

Sopify is a set of rules and Skills that installs into the AI coding tools you already use.

Does every question start a plan?

No. Ordinary questions and small fixes are handled directly. Sopify resumes an unfinished plan only when you ask to continue or use the current host's managed entry.

What actually travels with the repo?

Plans, decisions, and verification receipts can be tracked under .sopify/. The active-plan and handoff pointers stay gitignored by design.

Does switching hosts give every host identical capabilities?

No. Codex, Claude Code and Qoder are verified: the managed workflow has been run in a real session, not only installed. Copilot, Cursor, Antigravity and Trae are baseline: the installation is verified, and real-session evidence varies by host — see each host doc; Antigravity has been tested in real sessions. One Cursor install covers the IDE and local CLI; the CLI selects the plan, development, resume, and closeout entry when the request calls for it. Cloud Agent remains out of scope.

Is EvidentLoop required?

No. Sopify works on its own. EvidentLoop is an optional companion for auditable reviews of local Git changes.
